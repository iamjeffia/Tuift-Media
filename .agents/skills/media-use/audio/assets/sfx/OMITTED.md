# Bundled sound effects omitted

The upstream skill ships 19 `.mp3` sound effects here, taken from Pixabay and used under the
Pixabay Content License (see `CREDITS.md` and `manifest.json`). The licence covers use inside
derivative works such as rendered videos; this repository does not redistribute the audio files
on their own, so they are not included.

`manifest.json` and `CREDITS.md` are kept as upstream wrote them. To use the bundled-library path
described in `../../references/sfx.md`, install the skill from the upstream repository
(`npx hyperframes skills update media-use`) or put your own `.mp3` files in this folder under the
names listed in `manifest.json`. Without them, source sound effects through a provider as that
reference describes.

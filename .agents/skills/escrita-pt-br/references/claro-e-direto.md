# Claro e direto

Linguagem simples não é linguagem pobre. É a que o leitor entende na primeira leitura, sem reler e sem ajuda. Os princípios são os mesmos da prática de linguagem simples em geral (a norma ISO 24495-1 os resume): o conteúdo serve ao leitor, é fácil de achar, de entender e de usar.

## Comece pelo que importa

Ponha a conclusão, a resposta ou a ação na primeira frase. O contexto vem depois, se o leitor precisar dele.

| Antes                                                                                                     | Depois                                                                         |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Em razão de uma série de ajustes recentes na infraestrutura, informamos que o serviço ficará indisponível. | O serviço fica fora do ar amanhã, das 2h às 4h, para uma manutenção.          |

Cada parágrafo abre com a ideia dele. Quem só ler as primeiras frases deve entender o essencial.

## Frases curtas, uma ideia cada

- Mire em 15 a 20 palavras por frase. Passou de 30, quase sempre dá para dividir.
- Misture tamanhos. Uma frase muito curta depois de duas médias dá ritmo.
- Se a frase tem três vírgulas e dois "que", são duas ou três frases.

| Antes                                                                                                                                         | Depois                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| O relatório, que foi gerado ontem pela equipe de dados e que contém os números que o time comercial pediu, está disponível na pasta compartilhada. | A equipe de dados gerou o relatório ontem. Ele tem os números que o time comercial pediu e está na pasta compartilhada. |

## Ordem direta: quem faz, o quê, a quem

O português aceita muita inversão, mas o leitor processa melhor sujeito, verbo e complemento, nessa ordem. Deixe o ator na frente.

| Antes                                                    | Depois                                  |
| -------------------------------------------------------- | --------------------------------------- |
| Foi decidido pela diretoria o adiamento do lançamento.   | A diretoria adiou o lançamento.         |
| Ao ser recebido o pagamento, o acesso é liberado por nós. | Liberamos o acesso quando o pagamento chegar. |

## Voz ativa, com ator claro

A voz passiva não é erro. Serve quando o ator não importa ou é desconhecido ("O arquivo foi salvo"). O problema é a passiva usada para esconder quem faz, ou empilhada.

| Antes                                          | Depois                                 |
| ---------------------------------------------- | -------------------------------------- |
| O pedido foi analisado e foi aprovado.         | Analisamos o pedido e o aprovamos.     |
| Será realizada a conferência dos dados pelo setor. | O setor vai conferir os dados.     |

## Verbo no lugar do substantivo abstrato

O texto burocrático troca o verbo por "fazer + substantivo". Devolva a ação ao verbo.

| Em vez de                      | Escreva           |
| ------------------------------ | ----------------- |
| realizar a análise de          | analisar          |
| efetuar o pagamento            | pagar             |
| proceder à verificação         | verificar         |
| fazer uso de                   | usar              |
| dar início a                   | começar, iniciar  |
| tomar conhecimento de          | saber, descobrir  |
| fazer a instalação de          | instalar          |
| ter a necessidade de           | precisar de       |
| estar em condições de          | poder             |
| dar andamento a                | seguir com, tocar |

## Corte o que não carrega informação

Se a frase fica igual sem a expressão, tire a expressão.

| Enchimento                              | Alternativa                                  |
| --------------------------------------- | -------------------------------------------- |
| é importante ressaltar que              | (comece direto pelo fato)                    |
| vale destacar que, cabe salientar que   | (idem)                                       |
| no sentido de, com o objetivo de        | para                                         |
| tendo em vista que, em virtude de que   | como, porque                                 |
| a nível de                              | (corte) ou em, no âmbito de                  |
| no que diz respeito a, no que tange a   | sobre, quanto a                              |
| por meio da utilização de               | usando, com                                  |
| em linhas gerais, de modo geral         | (corte, ou diga o que é geral)               |
| basicamente, essencialmente, realmente  | (corte)                                      |
| na data de hoje, no momento atual       | hoje, agora                                  |

## Pleonasmos

Corte a palavra que repete o que o verbo ou o substantivo já diz.

- subir para cima, descer para baixo, entrar para dentro
- há dois anos atrás (use "há dois anos" ou "dois anos atrás")
- elo de ligação, acabamento final, surpresa inesperada, planejar antecipadamente
- segue em anexo (use "segue anexo" ou "anexo")
- encarar de frente, comparecer em pessoa, a seu critério pessoal

## Negativas duplas e frases que giram

Prefira a forma afirmativa.

| Antes                                          | Depois                              |
| ---------------------------------------------- | ----------------------------------- |
| Não é raro que o envio não seja concluído.     | O envio costuma falhar.             |
| Não é incomum que o prazo não seja cumprido.   | O prazo costuma atrasar.            |
| Não são poucos os clientes que não gostaram.   | Muitos clientes não gostaram.       |

## Concretize

Número, nome, prazo e exemplo valem mais que adjetivo.

| Antes                                    | Depois                                                  |
| ---------------------------------------- | ------------------------------------------------------- |
| O novo editor é muito mais rápido.       | O novo editor abre arquivos grandes em menos de 2 segundos. |
| Em breve, teremos novidades.             | Em dezembro, lançamos a exportação em PDF.              |

Se você não tem o dado, não o invente. Escreva o que se sabe e deixe a vaguidão de fora, em vez de enfeitá-la.

## Palavras que o leitor conhece

- Troque o termo raro pelo comum quando o sentido for o mesmo: "utilizar" por "usar", "adquirir" por "comprar", "auxiliar" por "ajudar", "possuir" por "ter", "iniciar" por "começar" (a depender do tom).
- Explique sigla e termo técnico na primeira vez. Depois use só a forma curta.
- Não use "o mesmo", "a mesma" como pronome ("Cancele o pedido e envie o mesmo por e-mail"). Escreva "ele".
- Evite "queísmo": "Acho que o fato de que o sistema que usamos…". Corte um "que" e a frase respira.

## Estrutura que ajuda a ler

- Título que diz o conteúdo, não o assunto: "Como trocar a senha", e não "Senhas".
- Lista quando os itens são parecidos e paralelos. Cada item começa do mesmo jeito (todos com verbo no infinitivo, por exemplo).
- Passos numerados quando a ordem importa. Uma ação por passo.
- Negrito só para o que a pessoa precisa achar de relance (nome de botão, aviso). Se tudo está em negrito, nada está.
- Parágrafos de três a cinco linhas. Um bloco grande de texto afasta o leitor.

## Teste final

Leia a frase em voz alta. Se faltar fôlego, divida. Se você não diria isso a uma pessoa, reescreva.

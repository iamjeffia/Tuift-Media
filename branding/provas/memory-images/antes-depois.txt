memory-images: memory before and after, same measurement on a private copy of the real database
Numbers only (sizes, counts, event types). Date 2026-11-15. Machine: Windows 11, Node 24, headless Chromium (Playwright).

Scenario. The biggest chat of the copy: an imported Claude Code chat, 2,279 stored events, 44 MB, 184 inline
images (171 on tool_call items, 13 on message items) = 41.5 MB of base64 inside the events. Its saved session
file is 129 MB (each screenshot is saved twice there). Server started headless on a copy of the database with
its own port; renderer = the real web app on a Vite dev server, opened in headless Chromium against that server.
Before = main at the start of this front. After = this branch. Both rows ran on fresh copies of the data.
The saved session grows while the owner works, so the "after" run read 1,969 events and the "before" run 1,923.
